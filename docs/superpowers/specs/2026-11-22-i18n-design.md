# English and Ukrainian interface

Approved in conversation: English by default; compact flag-coloured EN / UA switch in the header; no URL prefixes. Translate interface, accessibility labels, status messages and Excel headings; keep track and series names unchanged.

Account language lives in Supabase Auth user metadata (`locale`, en/uk), following the existing analysis preference. Guests use a year-long same-site cookie. Account preference takes precedence over cookie; first sign-in imports a valid guest cookie when no account preference exists. Initial server rendering and HTML lang use the resolved locale. Failed account saves show an error and allow retry without claiming persistence.

Approaches considered: locale URL prefixes offer separately linkable/indexable versions but complicate existing routes; cookie/account selection preserves links and suits this authenticated planning tool. User chose no prefixes. Builder decisions: shared React translation context and explicit dictionary, no extra dependency or database migration; standard Ukrainian code uk internally, UA on the switch.
