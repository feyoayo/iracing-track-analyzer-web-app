# English and Ukrainian Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Translate the site with account-persistent EN / UA selection.
**Architecture:** Shared dictionary/translator, server locale resolution and client context. Same-origin PUT saves verified account metadata and an HTTP-only locale cookie; server rendering prefers account locale. OAuth callback imports guest selection only for accounts without a locale.
**Tech Stack:** Next.js 15, React 19, Supabase Auth, Vitest.
**Spec:** docs/superpowers/specs/2026-11-22-i18n-design.md

## Global Constraints
English default; en/uk internal codes; EN / UA flag-coloured labels; no URL prefixes; preserve track and series names; no database migration.

## Review Focus
- Invalid locale values fall back to English and are rejected on writes.
- Account locale overrides another browser's cookie.
- Failed saves do not change persisted cookie or misrepresent success.
- Translation switching preserves page filters and names.
- Guest selection survives navigation, reload and first login.

## Execution notes

Implemented in the existing checkout, without adding dependencies or migrations. Switching updates shared client context without router.refresh: existing page effects would otherwise reload filter selections from server props. All translated UI, including server-page text via LocalizedText, subscribes to the context.

Review found translated canonical SelectItem values and ClassIcon inputs. Both have regression tests observed failing before the fixes and passing afterward. No deferred minor findings.

First-login locale import is best effort if Supabase cannot save the optional metadata: successful authentication continues and the guest cookie remains usable; explicit language changes report save failures and retain the previous language. Live cross-device/OAuth interaction was not exercised with a real account; verified account metadata behavior and OAuth precedence are covered by mocked boundary tests.

Browser access host unavailable; native Chrome access was not approved. HTTP smoke test of the production server verified English default, locale cookie writes, invalid-cookie fallback and Ukrainian SSR for /, /tracks, /series, /profile and /auth/error.
